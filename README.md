# TaldauAI

TaldauAI — прототип системы автоматического протоколирования совещаний для группы компаний «Самрук-Қазына». Система принимает запись совещания, формирует двуязычный транскрипт, определяет участников, выделяет поручения и помогает контролировать сроки исполнения. Прототип рассчитан на работу в закрытом контуре без внешних запросов в рантайме.

План работы и требования к сдаче: [HACKATHON_PLAN.md](HACKATHON_PLAN.md).

## Архитектура

Сейчас в репозитории реализован автономный фронтенд-прототип. Компоненты получают и изменяют данные только через `frontend/src/api.ts`. API-слой имитирует задержку 300–800 мс и хранит состояние в `localStorage`; начальные данные находятся в `frontend/src/mocks.ts`. Такая граница позволяет заменить заглушки реальными HTTP-вызовами без изменений страниц и компонентов.

Основные маршруты:

- `/` — список совещаний;
- `/new` — загрузка файла или запись с микрофона;
- `/meetings/:id` — обработка, участники, транскрипт, саммари и поручения;
- `/tasks` — общий контроль поручений и напоминаний.

## Технологии

- React 18, Vite и TypeScript;
- Tailwind CSS;
- компоненты shadcn/ui на базе Radix UI;
- React Router;
- MediaRecorder и Web Audio API для записи и индикации уровня звука.

## Фронтенд

### Требования

- Node.js 18 или новее;
- npm 9 или новее;
- современный Chromium, Firefox или Safari для записи с микрофона;
- разрешение браузера на использование микрофона для сценария «Записать сейчас».

### Установка

```bash
cd frontend
npm install
```

Все зависимости устанавливаются локально через npm. CDN и внешние сетевые запросы в приложении не используются.

### Переменные окружения

Для текущего прототипа переменные окружения не требуются. При подключении бэкенда адрес API следует передавать через локальный `.env`; файлы `.env` исключены из Git.

### Запуск

```bash
cd frontend
npm run dev
```

Vite выведет локальный адрес, обычно `http://localhost:5173`.

Проверка production-сборки:

```bash
cd frontend
npm run build
npm run preview
```

### Как проверить основной сценарий

1. Откройте главную страницу и выберите «Новое совещание».
2. Укажите название и дату.
3. Загрузите аудио/видео или откройте вкладку «Записать сейчас», разрешите микрофон, запишите и прослушайте фрагмент.
4. Подтвердите уведомление участников и отправьте запись на обработку.
5. На странице совещания дождитесь прохождения пяти этапов обработки.
6. Измените имя участника и убедитесь, что оно обновилось в транскрипте и поручениях.
7. Отредактируйте поручение и нажмите на цитату, чтобы перейти к исходной реплике.
8. Откройте «Контроль поручений», примените фильтры, создайте напоминание и отметьте поручение выполненным.

### Сторонние компоненты

Используются open-source библиотеки из `frontend/package.json`: React, Vite, TypeScript, Tailwind CSS, React Router, Radix UI, Lucide React, class-variance-authority, clsx и tailwind-merge. В прототипе нет внешних моделей и датасетов; все примеры совещаний являются локальными моковыми данными.
