# Локальное дообучение ASR

Пилот адаптирует **только выходной CTC-слой** текущей Mixed STT, оба речевых
энкодера заморожены. Это обучение весов, но не обучение модели с нуля и не
полный прогон KSC2. Основная конфигурация приложения автоматически не меняется.
Качество нового checkpoint проверяется до его подключения.

## Данные и разбиение

- [Tim2190/kazakh-codeswitch-asr](https://huggingface.co/datasets/Tim2190/kazakh-codeswitch-asr):
  31 фрагмент естественной русско-казахской речи, около 3,7 минуты.
  Полностью оставлен для финальной проверки; эталоны не попадают в обучение
  или выбор эпохи. Для ASR используется `transcript_verbatim`; служебные
  пометки в квадратных скобках удаляются, произнесённые обрывки слов сохраняются.
- [ISSAI KSC2](https://issai.nu.edu.kz/kz-speech-corpus/): около 1200 часов.
  Официальный архив на Hugging Face занимает около 80,8 ГБ. Пилот потоково
  читает начало первой части и выбирает 256 Train, 64 Dev, 64 Test фрагмента
  длительностью 0,5–20 секунд. Полный корпус не скачивается.
- Dev пилота — 20% **официальной Train-части**, назначенные по фиксированному
  хешу ID записи. Это не официальный Valid. Test берётся из официального Test.
  Нет надёжной разметки личности для выбранных файлов: раздельность говорящих
  между Train и Dev не гарантируется. Выбор первых доступных пар смещён по
  источнику и не представляет весь KSC2.
- SHA-256 каждого аудио проверяется перед обучением; совпадение аудио между
  выборками останавливает запуск. Ревизии обоих наборов зафиксированы в коде.
- Базовая Mixed STT уже обучалась на KSC2 по карточке автора. Поэтому KSC2
  не является полностью независимым тестом исходной модели. Пересечение
  Tim2190 с исходным обучением модели неизвестно; от нашего дообучения он отделён.
- Дополнительно проверяются пять существующих синтетических фраз из проекта:
  русский, казахский и смешанный контроль. Это небольшой регрессионный тест,
  а не репрезентативная оценка сохранения русского языка после адаптации.

Подготовка загружает только публичные данные. Обучение и оценка работают с
локальными файлами. Пользовательские совещания в эти выборки не включаются.

## Запуск

Сначала установить ML-окружение по [ML_RUN.md](ML_RUN.md), затем:

```bash
pip install -r requirements-training.txt
python -m training.prepare_corpora --ksc-train 256 --ksc-dev 64 --ksc-test 64
python -m training.adapt_ctc --epochs 3 --learning-rate 0.00001 \
  --output models/mixed-stt-adapted-v2 --report data/training/adaptation-v2.json
```

Подготовка ограничена 4 ГБ прочитанного сжатого потока и 2 ГБ ещё не
сопоставленных аудиофайлов. Эти лимиты — защита от незаметной загрузки всего
архива, а не точный расход диска: сохраняются также пары, оказавшиеся вне
итоговой выборки. Не увеличивать размеры выборки до полного корпуса этим
пилотным загрузчиком: большой корпус нужно подготовить отдельно с полным
официальным Train/Valid/Test и проверить группировку говорящих.

Второй шаг запускается на CPU, кэширует замороженные признаки FP32, затем
оптимизирует CTC-слой. Число эпох, seed и learning rate фиксируются в отчёте.
Целевые последовательности сохраняют наблюдаемую в исходной модели
конвенцию `_|текст|_` с разделителем слов `|`. Первый эксперимент без
граничных символов ухудшил разбиение слов; он сохранён отдельно в отчётах.
Неподдерживаемые символы в целевых текстах не удаляются молча: такие обучающие
примеры пропускаются с причиной в отчёте. Исходные веса не перезаписываются.
Повторный запуск требует нового `--output`; кэш признаков можно использовать
повторно, он привязан к хешу исходных весов и аудио.

Выбор эпохи делается по Dev WER; исходная модель участвует как эпоха 0.
Если улучшения на Dev нет, экспортируется исходный вариант. Последний
обученный слой отдельно сохраняется в `last_head.pt` для аудита эксперимента.
После выбора один раз считаются Test WER/CER у исходного и выбранного слоя.
Метрики суммируют число ошибок по всем фрагментам; регистр и пунктуация
нормализуются, казахские буквы сохраняются. Для сравнения используются целые
короткие записи и greedy-декодирование без VAD — это не замер длинного совещания.

Подключение проверенного checkpoint:

```bash
export TALDAU_ASR_ENGINE=mixed-ctc
export TALDAU_ASR_MODEL="$PWD/models/mixed-stt-adapted-v2"
```

Если тест смешанной речи ухудшился, модель не следует заменять. Новые
эксперименты после просмотра Test уже требуют новой независимой проверки.
Повышение точности ASR само по себе не доказывает улучшение диаризации,
ответственных, сроков или саммари; их проверяют сквозным тестом отдельно.

## Фактический запуск: 23 сентября 2026

Использованы 256 обучающих записей (32,38 минуты), 64 Dev (7,92 минуты),
64 Test (8,06 минуты), все выбранные KSC2-фрагменты — crowdsourced.
Загрузчик прочитал 2 123 008 000 байт сжатого архива. Дополнительно проверены
31 фрагмент Tim2190 и пять синтетических языковых контролей.
Обучались 72 239 параметров CTC-слоя, 3 эпохи, CPU, seed 42.

| Конфигурация | Dev WER | Dev CER | Решение |
|---|---:|---:|---|
| Исходная модель | 6,88% | 1,10% | Сохранена |
| Пилот 1, без граничных меток, lr=1e-4, эпоха 3 | 13,30% | 1,55% | Отклонён |
| Пилот 2, граничные метки, lr=1e-5, эпоха 3 | 7,03% | 1,12% | Отклонён |

Во втором пилоте поменялись и целевые метки, и шаг обучения: это сравнение
конфигураций целиком, не измерение вклада одного изменения. Обе конфигурации
выбрали эпоху 0; обучение не дало улучшения. Разница второго пилота — всего
одна дополнительная словная ошибка на 669 словах Dev, статистическая
значимость не утверждается. Приложение продолжает использовать исходные веса.

Финальная оценка **исходной/сохранённой модели**:

| Набор | WER | CER |
|---|---:|---:|
| 64 KSC2 Test | 9,31% | 1,96% |
| 31 Tim2190, буквальная разметка | 23,87% | 5,88% |

Эти числа не являются результатом улучшенного checkpoint: выбран исходный.
После первого запуска изменяли настройки по Dev, без использования
транскриптов Tim2190 для обучения. Сохранённые отчёты:
[пилот 1](examples/results/ctc-adaptation-pilot-v1.json),
[пилот 2](examples/results/ctc-adaptation-pilot-v2.json).
Хеши манифестов добавлены к этим двум отчётам после завершения запусков;
последующие запуски записывают их автоматически.

Экспорт TorchScript проверен повторной загрузкой и точным совпадением весов
выбранного слоя. 30 unit-тестов проходят. Для дальнейшей адаптации нужна
более разнообразная обучающая выборка, особенно смешанная разговорная речь;
простое повторение обучения на первых записях уже знакомого модели KSC2
не подтвердило улучшения.
